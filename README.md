# NYC Memories — Family Merge

This repository now contains the original family-vacation merge game again.

**Play:** https://stoffersen.github.io/Nyc2026/

The experimental four-level 3D NYC Family Quest and its 2D version were removed at the project owner's request.

The original merge game is available as `index.html` and `merge.html`. It uses falling photo tokens, point scoring, an unlockable family photo album and an original Web Audio soundtrack.

## Local testing

Run `node scripts/smoke-test.mjs`.

## Privacy

The repository is public, and the sprite at `assets/nyc-family-sprite.jpg` contains compressed photos of people from the family vacation. Please ensure that all depicted people consent to public sharing.
