# NYC 2026 — Neon Rooftops

A playable, original New York rooftop platform game. No dependencies: plain HTML5 Canvas and JavaScript.

## Play online
https://stoffersen.github.io/Nyc2026/

If not live: open [Settings → Pages](https://github.com/Stoffersen/Nyc2026/settings/pages), set **Build and deployment → Source → GitHub Actions**, then inspect [Actions](https://github.com/Stoffersen/Nyc2026/actions) and run **Deploy NYC 2026 to GitHub Pages** if needed. Each push to main triggers redeployment.

## Play locally
Open `index.html` in a modern browser.

## Controls
- Arrows or A/D: move
- Space, W or up arrow: jump and double-jump
- R: restart
- P: pause/resume
- Mobile: on-screen controls

## Features
Responsive canvas, animated layered NYC skyline, rooftop platforms, double-jump, enemies, crystals, spikes, checkpoints, lives, win screen and following camera.

## Roadmap
Handcrafted levels, character sprites, sound, browser tests, and additional mobile polish.

Original game identity; no reused Giana Sisters characters or assets.
